GETTING STARTED
1. Use CatScratch-Setup.exe, or extract the entire portable ZIP to a writable folder.
2. Install Npcap separately from https://npcap.com/#download if missing.
3. Start CatScratch.exe and accept the Windows administrator prompt.
   Cancelling the prompt prevents startup.
4. Teleport or change zones while CatScratch is running to receive fresh identity data.
5. Use borderless windowed mode to keep the meter visible above the game.

METER AND CONTROLS
Track your own damage while solo and confirmed current party members while grouped.
Rows show class emblems, name, CP, GS, DPS and share, with class-colored backgrounds. Received damage is separate.
Unknown values appear as dashes. Group-search room values need a received roster.
Personal combat shows HP-confirmed effective self healing and healing of others, excluding overheal. An asterisk marks incomplete confirmed totals; a dash means no amount could be confirmed.
An optional boss HP panel uses received health data. RTT is a passive TCP estimate.
Resize the meter, adjust opacity and scale, or use compact/normal layouts.
Click-through removes the outer frame and controls while keeping statistics visible.
The permanent control panel stays clickable and contains the version, module controls and single Settings gear. Its X is the only in-app Exit action. The DPS display can be disabled independently. Choose horizontal/vertical layout, anchors, pin and transparency under Settings > Appearance > Control panel. Save keeps Settings open; X closes and discards later unsaved edits.

DEFAULT SHORTCUTS — change them in Settings > Hotkeys
Shift+F4: toggle death recap
Shift+F5: show/hide DPS meter
Shift+F6: toggle Personal combat
Shift+F7: upcoming events
Shift+F8: boss timers
Shift+F9: pet tracker
Shift+F10: show/hide all windows, restoring the previously open set
Shift+F11: toggle click-through
Shift+F12: restart the meter measurement
Click a shortcut field, press the desired combination and Save.
App shortcuts pause while Settings is active.

BOSS PERSONAL BESTS
Open the small trophy icon in the control panel.
Real dungeon/world boss victories can improve six independent permanent bests:
highest DPS, damage, strongest hit and healing; fewest own deaths and least damage taken.
Records are separate for each character/server/class and are not limited to ten fights.
Test mode, recorded playback and incomplete or unqualified fights do not improve records.

LAST PLAYED WITH
Open the player icon beside the trophy for confirmed recent teammates.
Compact rows show name, class, server, last-played time and last received CP/GS.
Each player has an individual copy-name button. No expandable equipment panel is used.
The list persists per own character/server with no ten-player limit.
Stream mode masks displayed and copied names; original local files remain unchanged.

DEATH RECAP
The tombstone icon or Shift+F4 enables/disables the module.
On death, show the five latest received hits from the last ten seconds, with attackers, skills and red damage values. The compact window starts in the upper half of the screen.
Fresh positive own HP or a map reload dismisses the recap. It is not saved across restarts.
Two recorded resurrection methods were tested; a third still lacks a recording.

FIGHT HISTORY
Statistics selects live, current-session and saved fights.
Boss personal bests and Last played with use their own dedicated control-panel buttons.
Press Save after combat to keep a full fight. Automatic saving is disabled by default.
Full saved fights retain the ten newest records. Boss bests and recent players are independent.
Test fights cannot be saved as real fights or populate permanent personal records.

PETS, EVENTS AND SOUNDS
The control-panel paw toggles the Pet tracker. Show at most five incomplete pets, prioritizing fresh source monsters in sight and then the supported current region. Level-3 pets are hidden everywhere and disappear after the final confirmed soul loot. If no supported location is known, up to three incomplete recently attacked sources provide a fallback. Supported regions: Verteron, Altgard and Chaotic Lower Reshanta. No exact-distance ranking or game-memory access is used. Width is adjustable in Settings > Pets and using the bottom-right grip.
Saved progress is character-scoped; ~ marks last-known counts pending fresh login data.
Events and enabled boss timers within the next hour appear as movable cards.
Started entries leave Upcoming and appear exclusively in the movable Started events module.
The Upcoming clock opens the 24-hour event timeline. Enable Started events separately in Settings > Events; its placement and visibility are saved independently. Timeline favorites persist and have a subtle gold frame. Event/PvP/Boss use distinct colors.
Events: Open! + 3-minute countdown; Spacetime Rift: Open! + 10-minute countdown.
Bosses: Spawned for 2 minutes, without a countdown. Expired entries disappear automatically.
Boss observations can be estimates.
Event schedules are bundled community data; verify availability in game.
Optional custom WAV/MP3 sounds support preview and volume, up to ten seconds and ten MB.

UPDATES
Choose Stable or Beta in Settings > Updates.
With automatic updates enabled, check shortly after startup and every ten minutes.
Download, verify and extract updates in the background while the current meter runs.
A green Update! button replaces the CatScratch title inside the control panel only when preparation is complete. Otherwise the CatScratch title remains visible. No separate update popup is created, and panel position and size stay unchanged. Click it to apply prepared files and restart. No automatic restart occurs.
Both installed and portable copies support in-app updates in a writable folder.
Preserve userdata; remove old backups, staging and ZIP only after successful new startup.
Failed updates retain recovery files. Temporary update data uses userdata/temp/updates.
Promoted Stable builds return Beta subscribers to Stable; a later deliberate Beta choice persists.

PATCHNOTES
Versions appear in a left sidebar, with per-version notes and clickable contents on the right.
The ten newest version tabs are available. Bundled notes work offline.
Refresh from GitHub updates the history. The selected update channel filters versions.

LANGUAGES AND PRIVACY
Select English, German, Russian or French in Settings > General > Language.
English is the default and fallback for missing names. Patchnotes remain English.
Stream mode masks displayed/copied player names; saved files and captures retain originals.

DEBUG AND FEEDBACK
Settings > Capture & data > Recent debug buffer can retain up to the last 60 seconds.
It is disabled by default, capped at 32 MB of accounted packet storage and can be shorter under load.
Save recent debug exports a local PCAP to userdata/captures. Continuous recording is also available.
For group issues include joining/leaving; for revival issues include death and resurrection.
Captures can contain names. Nothing is uploaded automatically.
Feedback opens GitHub issue forms; reports must be in English and require a GitHub account.

LIMITATIONS AND LICENSE
Missing server data can leave damage, names, CP/GS or observed deaths incomplete.
Cached names alone do not confirm the own character. Local accelerators can affect RTT.
CatScratch passively captures traffic: no game-memory access, injection, game-file changes,
outgoing game packets or simulated game input are implemented. This is not publisher approval.
