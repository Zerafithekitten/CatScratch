CatScratch — EU/NA

SETUP
1. Extract the complete program folder to a writable location.
2. Install Npcap from https://npcap.com/#download if it is missing.
   The application offers to open the official page; installation is done by you.
3. Start CatScratch.exe, then teleport once or enter a new zone in game.
   Your character is confirmed only when fresh identity data arrives.
4. Use borderless windowed mode if the meter should remain visible above the game.

DISPLAY AND CONTROLS
The meter is a separate, movable, always-on-top Windows application.
The default compact layout is 300 × 300 with colored damage bars.
The header shows current Europe/Berlin time in 24-hour HH:mm format, including DST.
Fight duration is separate and marked with a stopwatch symbol.
Rows show class icon, player name, Combat Power (CP), Gear Score (GS), DPS,
total damage and damage share. Missing values are shown as dashes.
The footer shows total DPS and a separate RTT latency estimate.
RTT uses captured client TCP data and matching server acknowledgments only.
No extra network probes are sent. Server ACK delays can affect the estimate.
A local ping accelerator may expose only its local proxy connection.
RTT is unavailable until outgoing data and matching ACKs are captured on a confirmed
game flow, and returns to a dash after 15 seconds without a fresh sample.
The display refreshes approximately five times per second and remains visible
between fights. All built-in interface text is English.

Top-right gear: Settings, including HOTKEYS > Click-through.
Click a hotkey field and press the desired combination, then click Save.
Tab moves to the next field; Escape leaves the field without changing its shortcut.
App hotkeys pause while Settings is active. No keyboard hook is used.
Turquoise cursor symbol: clickable. Crossed-out cursor: click-through.
Default shortcut Ctrl+Shift+L toggles clickability for all display windows.
The cursor symbol can also enable click-through while the meter is clickable.
Settings and the system tray menu remain available in click-through mode.
The program starts clickable. Normal toggles do not show text or notifications.
Click-through also removes window backgrounds, borders, shadows, title bars and controls.
Damage rows and their contents remain visible, as do time, duration, DPS and RTT.
Event names, categories and countdowns remain without the event window frame.
Switch back using your hotkey or the tray menu to restore controls and backgrounds.
Settings windows remain opaque and clickable.
If a shortcut cannot be registered, an error explains how to change it.

Bottom controls: View, Events, and Statistics.
Events also opens from the system tray menu under Upcoming events.
Opening Events switches the display windows to clickable mode for positioning.
Drag the Upcoming events header or any card to move the event board.
Use your click-through hotkey to restore pass-through after positioning.
Event preferences have a solid dark background and always remain clickable.
The event window opens by default and reopens on restart unless closed with its X.
Saved event-window positions are moved back into the visible desktop when needed.
View provides compact mode, size presets, width/height sliders and opacity.
Drag the lower-right corner to resize; drag the display to move it.
Opacity can be set from 40% to 100%.
The top-right X exits the entire program, including all event and boss windows.
Ctrl+Shift+D only shows/hides the meter. Ctrl+Shift+R resets the measurement.
Settings > Updates > Check now checks for an update directly inside the meter.
Use the Setup installation for automatic updates of the complete application.

SOLO AND PARTY TRACKING
Your freshly confirmed own actor ID is counted even without a party roster.
Partial identity packets no longer block solo damage or erase the current fight.
Routine capture status updates and quiet traffic no longer discard your own actor ID.
Exiting the game still clears identity and requires fresh identification.
Until fresh name data arrives, your row is labeled You.
Confirmed members of your current party are included when a fresh roster arrives.
Other players, unknown attackers and same-name players on other servers are excluded.
Pets count only when an explicit owner ID identifies you or a confirmed party member.
The meter does not guess pet ownership from matching skills or damage factors.
A party change resets the running measurement. If the roster is not refreshed for
30 seconds, party tracking falls back to your own character; this conservative
interval still requires verification against the actual EU/NA game stream.
A capture restart, zone change or conflicting own actor ID requires fresh identity.
Cached names alone do not confirm your character.
Your own GS is decoded directly from the fresh own-character record, even solo.
This layout was verified against the Oct 13 user recording and the in-game GS.
Teleport once after starting the new version to receive fresh character data.
Other party members still require roster data. Missing or invalid fields remain dashes.
CP/GS are displayed when supplied by identity or roster data, never invented.
The server may omit damage data in crowded encounters, making results incomplete.

HISTORY
Only the ten newest completed fight statistics are retained, ordered by fight start.
Older fight files are deleted after saving and when opening an existing larger history.
The session list also retains ten completed fights.
Cleanup affects only the meter's own local fight statistics.

AUTOMATIC EVENTS
The small event window requires no manual event entry.
It shows only the next selected start within 60 minutes, including every selected
event starting at that exact same time. Later starts and past events are omitted.
Events appear as small dark cards with gold borders, arranged side by side.
The countdown updates every second; the height adjusts to the number of events.
Double-click a card, or right-click it, to open a separately movable event window.
The gear opens event selection, server region, width and independent opacity.
Europe is the default region; NA East and NA West are also available.
Default selection: Shugo Festival, Spacetime Rift and Dimensional Invasion.
Additional choices: Artifact Siege, Siege Bosses, Guardian Lord Nahma, Watcher Kaira.
The event settings also provide a button to open separate observed boss timers.
EU scheduling follows Europe/Berlin, including daylight saving time.
Source: https://shugo.gg/timers — checked Oct 12, 2026; source updated Oct 9, 2026.
These are community schedules, not officially confirmed Global times.
Recurring starts are calculated automatically from the bundled schedule.
Future schedule changes are not downloaded automatically. Verify availability in game.
Observed boss times may require opening the in-game boss list; estimates are marked.

DATA ACCESS
The application passively captures AION2.exe network traffic using Npcap.
No game-memory access, injection, game-file changes, outgoing game packets or
simulated game input are implemented. Only its own windows and files are changed.
Shared incoming packets may contain other players; filtering limits results and
new name caches to you and your party, rather than preventing shared packet receipt.
NPC and boss data are read for the requested timers.
This is not a statement of publisher approval.
Settings and statistics are stored in userdata inside the program folder.
Installed and portable copies use GitHub releases from Zerafithekitten/CatScratch.
Automatic checking and installation can be disabled in Settings.
Updates download a verified package, close all windows, replace program files and restart without Setup. Userdata is preserved. Existing Zerafi DPS Monitor installations use one final migration installer.
