# Altgard map overlay data

Static potential locations: https://questlog.gg/aion-2/en/map (world 1110, English, retrieved for the local prototype on 2026-10-22).

Base map: https://cdn.questlog.gg/aion-2/map/v3/World_D_A.webp . Map and game-symbol artwork belongs to its respective owners; CatScratch is an unofficial independent tool. Locations do not confirm current spawns. Personal Questlog account/progress data is not included.

Reference poses contain only numeric image transforms. The small title detector contains the game's Altgard map heading. No user screenshots, captures, player identities or personal settings are distributed.

The optional bundled image engine uses Python (PSF), NumPy (BSD), OpenCV / opencv-python (Apache-2.0), and PyInstaller (GPL-2.0 with its distribution exception). Their licenses are included with the bundled libraries. Source: tools/map-engine.
