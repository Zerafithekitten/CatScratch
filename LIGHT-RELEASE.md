# CatScratch light 1.0.0

A separate **DPS meter only** edition, downloaded and installed independently from full CatScratch.

- Compact DPS window with class emblems, class-colored fills, DPS, percentage share and incoming damage.
- Confirmed party membership, CP/GS and boss HP use the existing passive combat engine.
- Essential embedded settings: adapter, window width, background opacity and player rows; independent pin, reset and resize controls.
- No events, pets, hidden-cube alerts, boss-timer management, recap, history browser, comparisons, notifications, audio, autostart watcher or automatic updater.
- Own executable and settings directory; the full version's installation and settings stay separate.

**Download:** extract the entire **CatScratch-light-win-x64.zip** into its own folder and run **CatScratch.Light.exe**. Npcap is required; .NET is bundled. Use borderless windowed mode and teleport/change zones to confirm character/party identity.

**Maintenance:** Light changes only when the owner explicitly requests it. There are no automatic merges or updates from the full version. Any future Light update is a separate manual download. Full CatScratch remains the main development target.

Verification covers the shared combat engine, synthetic-party DPS and incoming damage, independent settings, embedded controls, product separation and complete exit through X.
