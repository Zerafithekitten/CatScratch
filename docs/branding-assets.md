# CatScratch identity assets

The app uses one shared cropped, angular cat profile (`Controls/CatSignature.cs`), a static mascot portrait and the CatScratch wordmark. The two transparent PNGs in `src/AionMeter.App/Assets/Branding/` were created with the built-in Imagegen tool from the owner-approved public banner and alert portrait. They contain no paid companion animation frames.

Final generation briefs:

- Wordmark: standalone exact CatScratch lettering from the approved banner; bold rounded white/lavender letters, small ear/tail flourish, transparent background, no other graphics or text.
- Mascot: established charcoal kitten with lavender eyes/forehead triangle/chest, pale muzzle and gold star pendant; welcoming smile and resting paws; remove alert exclamation mark; transparent background.

Settings use the mascot and wordmark in their existing header and the signature on every selected page. Other app windows receive a static, non-interactive signature through their adorner layer; large windows also use a faint corner wordmark. Large heading paw illustrations become mascot portraits, while functional buttons, application/tray paw icons and the optional golden supporter paw retain their identities. Compact overlay signatures stay small and subdued. The Hidden Cube alert retains its specific alert artwork; the animated companion is not decorated.

Brand adornments add no measured layout space, timers, animation clocks, settings or input targets. The original accessible title text is retained behind the control-panel wordmark. Shared native and sample rendering use the same signature drawing routine. Publication is a separate owner-approved step.
